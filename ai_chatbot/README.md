# FREEzzzGames AI Chat

Telegram AI chat module for FREEzzzGames.

## Characters
- FREEzzzy — main AI companion
- RakNaDne — informal community participant
- mamkinBlogger — blogger/content persona
- zadr0t — geek/game/tech persona
- tipoFUN — entertainment persona

## Flow
Telegram Group -> Telegram Bot API -> Python backend -> AI API -> Telegram.

The five personalities are implemented as one bot, so the group sees one Telegram bot account while the AI chooses the appropriate character for each response.

## Setup
1. Create the Telegram bot with @BotFather.
2. Copy `.env.example` to `.env` and fill the secrets.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run `python bot.py`.
5. Add the bot to the target group and configure its group message access in Telegram.

## Safety and stability
- Secrets are environment variables and must not be committed.
- Context is limited to the latest 24 messages per chat.
- Replies have a minimum interval to prevent spam.
- Spontaneous participation is probabilistic; direct replies/mentions take priority.
- Bot-to-bot loops are not generated by this module.
